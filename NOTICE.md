# Source and licensing

This is an independent collection of extracted libraries and new WebAssembly/HTTP adapters, derived from the repositories at https://github.com/storytold. It is not an upstream release or a claim of full application parity.

The root MIT licence applies to new repository orchestration and adapter code where no other licence is specified. Vendored source and assets retain their original licences, notices and attribution in each package. The root licence does not relicense third-party material. Font licences are included alongside the font files. Rust and npm dependencies carry their own licences.

Each package records its source repository, commit and extraction scope. Desktop applications, native device drivers, model weights, corpora, account credentials and deployment configuration are not part of this collection. See the README coverage table for the supported component in each package.
